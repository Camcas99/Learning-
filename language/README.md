# Language

Notes, vocabulary, and practice for learning a language.

## How this folder is organized

- `README.md` — this overview and the study plan
- Add new files as you go, for example:
  - `vocab.md` — new words and phrases
  - `grammar.md` — rules and examples
  - `log.md` — dated notes on what you practiced

## Study approach

- **Retrieval practice:** quiz yourself from memory before looking at notes.
- **Spaced repetition:** review material at growing intervals (1 day, 3 days, 1 week, ...).
- **Interleaving:** mix vocab, grammar, listening, and speaking in one session instead of blocking by topic.
